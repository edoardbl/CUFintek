📖 1. Pendahuluan

Tentang Aplikasi

Aplikasi Penagihan Credit Union adalah sistem berbasis web untuk membantu petugas koperasi dalam mengelola penagihan kredit, kunjungan lapangan, penanganan anggota menunggak, dan pelaporan.

Fitur Utama

📊 Dashboard Real-timeStatistik tagihan, tunggakan, dan % KL
👥 Data AnggotaInfo lengkap + saldo Pasallo & Sepu'
🏠 KunjunganSingle, Tim, & Multi-Anggota
📝 PenangananTelp/WA + Persuratan (SP1-SP3)
💰 SetoranBatch input + Approval admin
📈 StatistikPer aktivis, per staf, rekap bulanan
🖨️ LaporanKartu Kontrol, KPKL, Rekap KPKL
📥 Import DataAuto-fix + Mapping template

Role & Level Pengguna

LevelAkses Utama
Pengurus / KomiteSemua fitur + approve setoran
ManagerSemua fitur + admin tools
StafKelola anggota binaan aktivis
AktivisKelola anggota sendiri

🏠 3. Beranda (Dashboard)

Setelah login, halaman pertama adalah Beranda. Berisi:

Dashboard (6 Kartu)

  • Total Anggota — jumlah semua anggota terdaftar
  • Total Anggota Meminjam — jumlah anggota yang punya pinjaman aktif
  • Total Saldo Pinjaman — total saldo pinjaman semua anggota
  • Saldo Tertunggak — total saldo yang menunggak
  • Belum Bayar — jumlah anggota yang belum bayar
  • % KL (Kredit Lalai) — persentase kredit lalai

Kartu Statistik Hari Ini

Menampilkan ringkasan kunjungan hari ini:

  • 📝 Jumlah kunjungan
  • 💰 Total nominal terkumpul
  • Breakdown status: Bayar / Janji / Belum / Tidak Ditemui / Pindah
  • 🏆 Top 3 petugas hari ini

Kartu Pengingat

Muncul otomatis kalau ada:

  • ⚠️ Terlewat — janji bayar atau kunjungan ulang yang sudah lewat
  • 💰 Janji Bayar — janji bayar dalam 7 hari ke depan
  • 🏠 Kunjungan Ulang — kunjungan ulang dalam 7 hari ke depan

Menu Cepat

  • 🏠 Kunjungan Multi — kunjungi 2-10 anggota sekaligus
  • 💰 Input Setoran — input setoran ke kantor

Pencarian & Filter

  • 🔍 Search box — cari nama / CIF / desa / NoRek
  • 📥 CSV — export daftar ke Excel/CSV
  • 📍 Filter Aktivis — tampilkan hanya anggota dari aktivis tertentu
  • ⚙️ Filter Menunggak — tampilkan hanya yang menunggak, atau semua

👥 4. Daftar & Detail Anggota

Daftar Anggota

Di beranda, semua anggota ditampilkan dalam bentuk kartu. Setiap kartu berisi:

  • Nama lengkap & nama panggilan
  • CIF (nomor anggota)
  • Jenis pinjaman (badge kuning)
  • Alamat & desa
  • Tanggal jatuh tempo (JTO)
  • Staf pendamping & aktivis
  • Saldo pinjaman
  • Tagihan normal & tagihan program
⚠️ Kartu warna merah muda = anggota menunggak

Detail Anggota

Klik kartu anggota → muncul halaman detail dengan:

Info Lengkap

  • Nama, NoRek, CIF, jenis pinjaman
  • No HP (dengan tombol Edit dan Salin)
  • Alamat lengkap
  • Tanggal jatuh tempo
  • Saldo pinjaman, tagihan normal, tagihan program
  • Lama menunggak & keterangan
  • Saldo Pasallo' & Saldo Sepu'

Rumus Tagihan (Penting!)

📐 Rumus Tagihan Normal:
Angsuran = PokokJT + TunggakanPokok (kalau > 0), atau NilaiAngsuran (kalau = 0)
Total = Angsuran + Bunga + Denda + SimpananStandar → dibulatkan ke 10.000
📐 Rumus Tagihan Program:
Angsuran = PokokJT + TunggakanPokok (kalau > 0), atau Buffer (kalau = 0)
Total = Angsuran + Bunga + Denda + SimpananStandar → dibulatkan ke 10.000

Tombol Aksi

  • 📞 Telepon — langsung panggil nomor HP
  • 💬 WhatsApp — kirim pesan tagihan via WA
  • 🗺️ Maps — buka lokasi di Google Maps
  • 💳 Kirim Info Transfer — kirim nomor rekening kantor via WA

Tombol Penanganan

  • 📝 Proses Penanganan — pilih jenis penanganan
  • 🏠 Kunjungan Multi-Anggota — kunjungi beberapa anggota
  • 📄 Cetak KPKL (PDF) — cetak Kartu Penanganan Kredit Lalai

🏠 5. Kunjungan

Kunjungan Langsung (1 Anggota)

Langkah 1: Buka detail anggota
Langkah 2: Klik "PROSES PENANGANAN" → "Kunjungan Langsung"
Langkah 3: Isi form:
  • 📅 Tanggal kunjungan
  • ✅ Status kunjungan (7 pilihan)
  • 💰 Nominal bayar (kalau ada)
  • 📝 Catatan
  • 📷 Foto bukti (kamera/galeri)
  • ✍️ Tanda tangan anggota
Langkah 4: Klik "SIMPAN KUNJUNGAN"
💡 Tips: Foto otomatis diberi watermark (tanggal, lokasi, nama petugas).

Penagihan Tim

Kalau Anda menagih bersama petugas lain:

Langkah 1: Klik "Proses Penanganan" → "Penagihan Tim"
Langkah 2: Pilih petugas yang ikut (minimal 2 orang)
Langkah 3: Isi status, nominal, foto, TTD
Langkah 4: Klik "SIMPAN"
✅ Keuntungan: Cukup 1 orang input. Kunjungan dihitung untuk semua petugas. Setoran tetap 1x.

Kunjungan Multi-Anggota (2-10 Anggota)

Langkah 1: Dari beranda → "Kunjungan Multi"
Langkah 2: Cari & pilih 2-10 anggota
Langkah 3: Isi status & nominal per anggota
Langkah 4: Isi catatan, foto, TTD (berlaku semua)
Langkah 5: Klik "SIMPAN"

📞 6. Penanganan (Telp/WA)

Untuk mencatat hasil telepon atau WhatsApp:

Langkah 1: Buka detail anggota → "Proses Penanganan" → "Telepon / WA"
Langkah 2: Klik tombol Telepon atau WhatsApp
Langkah 3: Isi hasil telpon/WA (wajib)
Langkah 4: Isi tanggal janji (kalau ada)
Langkah 5: Klik "SIMPAN PENANGANAN"
💡 WhatsApp otomatis pakai template: Pesan tagihan sudah otomatis terisi. Cukup klik kirim.

✉️ 7. Persuratan

Menu Persuratan (di sidebar) untuk kelola semua surat.

Halaman Utama Persuratan

Ada 3 menu:

  • 📄 Daftar Surat
  • ➕ Buat Surat Baru
  • 📊 Rekap Persuratan

Buat Surat Baru

Langkah 1: Pilih Anggota (combobox pencarian)
Langkah 2: Pilih Jenis Surat (Surat Tagihan / SP1 / SP2 / SP3)
Langkah 3: Nomor surat otomatis terisi (bisa diubah manual)
Langkah 4: Isi tanggal surat & catatan
Langkah 5: Klik "SIMPAN SURAT" → tanya cetak

Daftar Surat

  • Filter by jenis surat
  • Filter by bulan
  • Pencarian by nama/nomor
  • Cetak ulang
  • Hapus (admin only)

Rekap Persuratan

  • Total surat per bulan
  • Per jenis surat (Tagihan, SP1, SP2, SP3)
  • Per petugas
✨ Format Surat: Surat Tagihan, SP1, SP2, SP3 dengan kop surat, nomor otomatis, rincian tunggakan, dan tanda tangan manager.

💰 8. Setoran

Untuk mencatat setoran dari anggota ke kantor:

Langkah 1: Dari beranda → klik "Input Setoran"
Langkah 2: Klik "TAMBAH ANGGOTA" untuk tambah baris
Langkah 3: Cari & pilih anggota
Langkah 4: Isi nominal setoran
Langkah 5: Ulangi untuk anggota lain
Langkah 6: Isi tanggal & catatan
Langkah 7: Klik "SIMPAN SEMUA SETORAN"
⚠️ Penting: Setoran menunggu approval dari admin sebelum dihitung sah.

📥 12. Import Data

Menu Import Data untuk upload data dari Excel.

Langkah Import

Langkah 1: Pilih Tabel Tujuan (01_MasterAnggota, 02_DataPinjaman, 03_DataSimpanan, 04_DataTagihan, 05_Petugas)
Langkah 2: Upload file Excel/CSV
Langkah 3: Preview & Mapping kolom (otomatis dari template)
Langkah 4: Pilih mode import:
  • ➕ Tambah Baru — skip duplikat
  • 🔄 Update — timpa yang ada
  • 🔃 Ganti Semua — hapus dulu
Langkah 5: Klik "PROSES IMPORT"

Auto-Fix saat Import

Sistem otomatis memperbaiki:

  • CIF dinormalisasi (hindari notasi ilmiah)
  • NoHP dinormalisasi (format 62xxx)
  • Tanggal konversi dari serial Excel
  • Nama panggilan, alamat, desa (dari master)
  • Jenis pinjaman dikonversi ke kode
  • Kolom turunan dihitung otomatis
⚠️ URUTAN IMPORT YANG BENAR:
  1. 01_MasterAnggota
  2. 02_DataPinjaman
  3. 03_DataSimpanan
  4. 04_DataTagihan
  5. Jalankan "Rehitung Tagihan" (lihat bawah)

Rehitung Tagihan (Setelah Import 04)

⚠️ WAJIB: Setelah import 04_DataTagihan, jalankan Rehitung Tagihan dari Apps Script Editor:
  1. Buka Apps Script Editor
  2. Pilih fungsi rehitungTagihanOtomatis
  3. Klik ▶️ Run
Tanpa langkah ini, Tagihan Normal & Program tidak akan sesuai.

📅 13. Alur Kerja Harian

Pagi (07:00 - 09:00)

  1. Login ke aplikasi
  2. Cek Dashboard — perhatikan angka hari ini
  3. Cek Pengingat — ada janji bayar / kunjungan ulang hari ini?
  4. Cek Filter Menunggak — cari yang perlu dikunjungi

Siang (09:00 - 15:00)

  1. Kunjungi anggota (single/tim/multi)
  2. Input status kunjungan di aplikasi (langsung saat di lokasi)
  3. Foto bukti + tanda tangan
  4. Kirim WA untuk info transfer (kalau ada)

Sore (15:00 - 17:00)

  1. Cek semua kunjungan sudah ter-input
  2. Input setoran (kalau ada bayar tunai)
  3. Cetak surat (Surat Tagihan / SP1 / SP2 / SP3) untuk yang perlu

Malam (17:00+)

  1. Cek Statistik Hari Ini
  2. Cek Top Petugas
  3. Rencana kunjungan besok

🔧 14. Troubleshooting

Aplikasi Lambat Loading

  • Refresh halaman (Ctrl+Shift+R)
  • Cek koneksi internet
  • Tunggu 5-10 detik pertama (cache warm)
  • Refresh lagi — harus lebih cepat

Foto Tidak Ter-upload

  • Cek ukuran foto — max 10 MB
  • Kompres dulu dengan aplikasi editor
  • Coba ambil ulang dari kamera

GPS Tidak Terdeteksi

  • Buka pengaturan browser → izinkan akses lokasi
  • Keluar ruangan atau cari sinyal
  • Foto tetap bisa disimpan (tanpa koordinat)

Data Tidak Muncul

  • Hard refresh (Ctrl+Shift+R)
  • Cek filter aktivis — mungkin semua ter-filter
  • Cek filter menunggak
  • Logout & login ulang

Tagihan Tidak Sesuai

  • Cek sheet 04_DataTagihan — nilai mentah
  • Cek sheet 02_DataPinjaman — PokokPinjaman & Tenor
  • Jalankan Rehitung Tagihan dari Editor

Lupa Password

Hubungi admin → admin reset password lewat Setup Petugas.

Setoran Pending Terus

Setoran menunggu approval admin. Hubungi admin untuk approve.

❓ 16. FAQ (Pertanyaan Umum)

Q: Lupa password, bagaimana?

A: Hubungi admin. Admin reset password via Menu Admin → Setup Petugas → Reset Password.

Q: Foto tidak ter-upload, kenapa?

A: Cek ukuran foto. Maksimal 10 MB. Kompres dulu kalau lebih.

Q: GPS tidak terdeteksi, bagaimana?

A: Buka pengaturan browser → izinkan akses lokasi.

Q: Setoran saya pending terus, kenapa?

A: Setoran menunggu approval dari admin.

Q: Bagaimana cara cetak surat ulang?

A: Menu Persuratan → Daftar Surat → cari surat → klik 🖨️ Cetak Ulang.

Q: Angka statistik berbeda dengan kemarin, kenapa?

A: Statistik hari ini di-reset harian. Untuk data bulanan, lihat di Rekap Bulanan.

Q: Tagihan normal & program beda, kenapa?

A: - Normal = pakai angsuran penuh (PokokJT + TunggakanPokok, atau NilaiAngsuran) - Program = pakai PokokJT + TunggakanPokok, atau Buffer (untuk keringanan)

Q: Kenapa total tagihan dibulatkan?

A: Pembulatan ke 10.000 memudahkan pembayaran. Selisih pembulatan ditambahkan ke Angsuran Pinjaman (khusus di surat).

Q: Bagaimana cara ubah kota di surat?

A: Menu Admin → Setup TP → field "Kota Header Surat". Isi kota baru, simpan. Surat baru akan pakai kota ini.

Q: Bagaimana cara upload kop surat?

A: Menu Admin → Persuratan → Kop Laporan → upload gambar. Kop akan muncul di semua surat & laporan.

Q: Apakah data bisa di-backup?

A: Ya. Menu Admin → Backup Database → Backup Sekarang. File backup tersimpan di Google Drive.
