🔐 1. Login & Navigasi

Cara Login

Langkah 1: Buka link aplikasi di browser (HP / komputer)
Langkah 2: Isi Username dan Password Anda
Langkah 3: (Opsional) Centang "Ingat saya" supaya tidak perlu login ulang
Langkah 4: Klik tombol "MASUK APLIKASI"
💡 Tips: Klik ikon 👁️ di kolom password untuk melihat password yang Anda ketik — menghindari salah ketik.

Navigasi Utama

Setelah login, Anda akan melihat 4 menu di bawah:

Menu Fungsi
🏠 Beranda Daftar anggota, dashboard, statistik hari ini
📊 Statistik Statistik per aktivis & per staf
📂 Rekap Rekap bulanan, rekap setoran, cetak laporan
👤 Profil Edit profil, ganti password, logout

Menu Sidebar

🏠 2. Beranda

Setelah login, halaman pertama adalah Beranda. Berisi:

Dashboard (6 Kartu)

  • Total Anggota — jumlah semua anggota terdaftar
  • Total Anggota Meminjam — jumlah anggota yang punya pinjaman aktif
  • Total Saldo Pinjaman — total saldo pinjaman semua anggota
  • Saldo Tertunggak — total saldo yang menunggak
  • Belum Bayar — jumlah anggota yang belum bayar
  • % KL (Kredit Lalai) — persentase kredit lalai

Kartu Statistik Hari Ini

Menampilkan ringkasan kunjungan hari ini:

  • 📝 Jumlah kunjungan
  • 💰 Total nominal terkumpul
  • Breakdown status: Bayar / Janji / Belum / Tidak Ditemui / Pindah
  • 🏆 Top 3 petugas hari ini

Kartu Pengingat

Muncul otomatis kalau ada:

  • ⚠️ Terlewat — janji bayar atau kunjungan ulang yang sudah lewat
  • 💰 Janji Bayar — janji bayar dalam 7 hari ke depan
  • 🏠 Kunjungan Ulang — kunjungan ulang dalam 7 hari ke depan

Menu Cepat

  • 🏠 Kunjungan Multi — kunjungi 2-10 anggota sekaligus
  • 💰 Input Setoran — input setoran ke kantor

Pencarian & Filter

  • 🔍 Search box — cari nama / CIF / desa / NoRek
  • 📥 CSV — export daftar ke Excel/CSV
  • 📍 Filter Aktivis — tampilkan hanya anggota dari aktivis tertentu
  • ⚙️ Filter Menunggak — tampilkan hanya yang menunggak, atau semua

👥 3. Daftar & Detail Anggota

Daftar Anggota

Di beranda, semua anggota ditampilkan dalam bentuk kartu. Setiap kartu berisi:

  • Nama lengkap & nama panggilan
  • CIF (nomor anggota)
  • Jenis pinjaman (badge kuning)
  • Alamat & desa
  • Tanggal jatuh tempo (JTO)
  • Staf pendamping & aktivis
  • Saldo pinjaman
  • Tagihan normal & tagihan program
⚠️ Kartu warna merah muda = anggota menunggak

Detail Anggota

Klik kartu anggota → muncul halaman detail dengan:

Info Lengkap

  • Nama, NoRek, CIF, jenis pinjaman
  • No HP (dengan tombol Edit dan Salin)
  • Alamat lengkap
  • Tanggal jatuh tempo
  • Saldo pinjaman, tagihan normal, tagihan program
  • Lama menunggak & keterangan
  • Saldo Pasallo' & Saldo Sepu'

Tombol Aksi

  • 📞 Telepon — langsung panggil nomor HP
  • 💬 WhatsApp — kirim pesan tagihan via WA
  • 🗺️ Maps — buka lokasi di Google Maps
  • 💳 Kirim Info Transfer — kirim nomor rekening kantor via WA

Tombol Penanganan

  • 📝 Proses Penanganan — pilih jenis penanganan
  • 🏠 Kunjungan Multi-Anggota — kunjungi beberapa anggota
  • 📄 Cetak KPKL (PDF) — cetak Kartu Penanganan Kredit Lalai

Riwayat

  • 📋 Riwayat Penanganan — daftar surat/telepon/WA
  • 📜 Riwayat Kunjungan — daftar kunjungan dengan foto & TTD
  • 📞 Riwayat Update No HP — log perubahan nomor HP

🏠 4. Kunjungan

Kunjungan Langsung (1 Anggota)

Langkah 1: Buka detail anggota
Langkah 2: Klik "PROSES PENANGANAN" → "Kunjungan Langsung"
Langkah 3: Isi form:
  • 📅 Tanggal kunjungan (kalau tidak dikunci admin)
  • ✅ Status kunjungan (7 pilihan)
  • 💰 Nominal bayar (kalau ada)
  • 📝 Catatan
  • 📷 Foto bukti (kamera/galeri)
  • ✍️ Tanda tangan anggota
Langkah 4: Klik "SIMPAN KUNJUNGAN"
💡 Tips: Foto otomatis diberi watermark (tanggal, lokasi, nama petugas). Jadi tidak perlu edit manual.

Penagihan Tim (Beberapa Petugas)

Kalau Anda menagih bersama petugas lain:

Langkah 1: Klik "Proses Penanganan" → "Penagihan Tim"
Langkah 2: Pilih petugas yang ikut (minimal 2 orang)
Langkah 3: Isi status, nominal, foto, TTD (sama seperti kunjungan biasa)
Langkah 4: Klik "SIMPAN"
✅ Keuntungan: Cukup 1 orang input. Kunjungan dihitung untuk semua petugas. Setoran tetap 1x (tidak dobel).

Kunjungan Multi-Anggota (2-10 Anggota)

Kalau Anda mengunjungi beberapa anggota sekaligus:

Langkah 1: Dari beranda → "Kunjungan Multi"
Langkah 2: Cari & pilih 2-10 anggota (centang)
Langkah 3: Isi status & nominal per anggota
Langkah 4: Isi catatan, foto, TTD (berlaku semua)
Langkah 5: Klik "SIMPAN"

📞 5. Penanganan

Telepon / WA

Untuk mencatat hasil telepon atau WhatsApp:

Langkah 1: Buka detail anggota → "Proses Penanganan" → "Telepon / WA"
Langkah 2: Klik tombol Telepon atau WhatsApp — otomatis buka aplikasi
Langkah 3: Isi hasil telpon/WA (wajib)
Langkah 4: Isi tanggal janji (kalau ada)
Langkah 5: Klik "SIMPAN PENANGANAN"
💡 WhatsApp otomatis pakai template: Pesan tagihan sudah otomatis terisi. Cukup klik kirim.

Persuratan

Untuk membuat surat resmi (Surat Tagihan, SP1, SP2, SP3):

Langkah 1: Buka detail anggota → "Proses Penanganan" → "Persuratan"
Langkah 2: Pilih jenis surat (Surat Tagihan / SP1 / SP2 / SP3)
Langkah 3: Isi nomor surat (dari kantor)
Langkah 4: Isi tanggal surat
Langkah 5: Upload bukti pengiriman (opsional)
Langkah 6: Klik "SIMPAN" → akan muncul pilihan "Cetak Sekarang?"

💰 6. Setoran

Untuk mencatat setoran dari anggota ke kantor:

Langkah 1: Dari beranda → klik "Input Setoran"
Langkah 2: Klik "TAMBAH ANGGOTA" untuk tambah baris
Langkah 3: Cari & pilih anggota (nama, NoRek, atau CIF)
Langkah 4: Isi nominal setoran
Langkah 5: Ulangi untuk anggota lain (kalau perlu)
Langkah 6: Isi tanggal setoran & catatan (opsional)
Langkah 7: Klik "SIMPAN SEMUA SETORAN"
⚠️ Penting: Setoran akan menunggu approval dari admin. Setelah di-approve, baru dihitung sebagai setoran sah.

📊 7. Statistik & Rekap

Statistik Per Aktivis

Menu 📊 Statistik → Statistik Per Aktivis

  • Ranking aktivis berdasarkan % penyelesaian
  • Total pinjaman, sudah bayar, belum bayar
  • Jumlah kunjungan bulan ini
  • Total nominal terkumpul
  • Staf pendamping & daftar desa

Klik kartu aktivis → lihat daftar anggota yang di-handle

Statistik Per Staf

Menu 📊 Statistik → Statistik Per Staf

  • Ranking staf berdasarkan % penyelesaian
  • Jumlah aktivis binaan
  • Daftar aktivis binaan (dengan % masing-masing)

Rekap Bulanan Saya

Menu 📂 Rekap → Rekap Bulanan Saya

Menampilkan daftar anggota yang Anda tangani bulan ini, status kunjungan, dan total dibayar.

Rekap Bulanan Semua (Admin/Manager/Pengurus)

Menu 📂 Rekap → Rekap Bulanan Semua

Pilih petugas & bulan → lihat rekap lengkap.

🖨️ 8. Cetak Laporan

Menu 🖨️ Cetak Laporan menyediakan 4 jenis laporan:

Laporan Kegunaan
Kartu Kontrol Staf Rekap penagihan per staf per bulan
Kartu Kontrol Aktivis Rekap kunjungan per aktivis per bulan
Data Rekap KPKL Rekap KPKL semua wilayah
KPKL Kartu Kredit Lalai per anggota

Cara Cetak

Langkah 1: Pilih jenis laporan
Langkah 2: Pilih petugas & bulan (atau bulan saja)
Langkah 3: Klik "PREVIEW LAPORAN"
Langkah 4: Preview muncul di tab baru
Langkah 5: Klik "Cetak / Simpan PDF"

✉️ 9. Persuratan

Menu ✉️ Persuratan untuk kelola semua surat:

Daftar Surat

  • Lihat semua surat terkirim
  • Filter by jenis surat (Tagihan / SP1 / SP2 / SP3)
  • Cari by nama / nomor surat
  • Klik 🖨️ Cetak untuk cetak ulang
  • Klik 🗑️ Hapus (khusus admin) untuk hapus

Buat Surat Baru

Langkah 1: Cari & pilih anggota
Langkah 2: Pilih jenis surat (otomatis generate nomor)
Langkah 3: Nomor surat terisi otomatis — bisa diubah manual
Langkah 4: Isi tanggal surat & catatan
Langkah 5: Klik "SIMPAN SURAT" → otomatis tanya cetak

Rekap Persuratan

Lihat jumlah surat per jenis per bulan.

❓ 11. Pertanyaan Umum (FAQ)

Q: Lupa password, bagaimana?

A: Hubungi admin. Admin bisa reset password Anda via Menu Admin → Setup Data Petugas → Reset Password.

Q: Foto tidak ter-upload, kenapa?

A: Cek ukuran foto. Maksimal 10 MB. Kalau lebih, kompres dulu atau ambil ulang.

Q: GPS tidak terdeteksi, bagaimana?

A: Buka pengaturan browser → izinkan akses lokasi. Kalau masih gagal, coba keluar ruangan atau cari sinyal.

Q: Bagaimana kalau salah input kunjungan?

A: Kalau kunjungan multi-anggota, admin bisa edit/hapus. Kalau single, hubungi admin untuk perbaikan.

Q: Setoran saya pending terus, kenapa?

A: Setoran menunggu approval dari admin. Hubungi admin untuk approve.

Q: Bagaimana cara cetak surat ulang?

A: Menu Persuratan → Daftar Surat → cari surat → klik 🖨️ Cetak.

Q: Angka statistik saya berbeda dengan kemarin, kenapa?

A: Data kunjungan di-reset harian untuk Statistik Hari Ini. Untuk data bulanan, lihat di Rekap Bulanan.

Q: Bagaimana cara menghubungi kantor?

A: Cek di Profil → Tentang Aplikasi atau hubungi admin langsung.

Q: Apa itu "Cloud Storage"?

A: Cloud Storage adalah penyimpanan online tempat aplikasi menyimpan data backup dan file. Anda tidak perlu tahu detail teknis — semua otomatis.
