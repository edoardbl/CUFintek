📖 1. Pendahuluan

Tentang Aplikasi

Aplikasi Penagihan Credit Union adalah sistem berbasis web untuk membantu petugas koperasi dalam mengelola penagihan kredit, kunjungan lapangan, penanganan anggota menunggak, dan pelaporan.

Fitur Utama

📊 Dashboard Real-timeStatistik tagihan, tunggakan, dan % KL
🎯 Target PenangananRencanakan kunjungan harian BARU
👥 Data AnggotaInfo lengkap + saldo Pasallo & Sepu'
💬 WA PengingatKirim pengingat massal BARU
🏠 KunjunganSingle, Tim, & Multi-Anggota
📡 Mode OfflineKerja tanpa internet BARU
📝 PenangananTelp/WA + Persuratan (SP1-SP3)
💰 SetoranBatch input + Approval
📈 StatistikPer aktivis, per staf, rekap bulanan
🖨️ LaporanKartu Kontrol, KPKL, Rekap KPKL

Role & Level Pengguna

LevelAkses Utama
Pengurus / KomiteLihat semua data + approve setoran
ManagerKelola tim & lihat semua data
StafKelola anggota binaan aktivis
AktivisKelola anggota sendiri

🏠 3. Beranda (Dashboard)

Setelah login, halaman pertama adalah Beranda. Berisi:

Badge Target BARU

🎯 Badge Target Hari Ini
Muncul otomatis kalau Anda punya target aktif. Menampilkan:
  • Progress target hari ini (X/Y selesai)
  • Status cache offline (✅ Siap / ⚠️ Belum diunduh)
  • Tombol "Lihat →" ke halaman target

Dashboard (6 Kartu)

  • Total Anggota — jumlah semua anggota terdaftar
  • Total Anggota Meminjam — jumlah anggota yang punya pinjaman aktif

Kartu Statistik Hari Ini

Menampilkan ringkasan kunjungan hari ini:

  • 📝 Jumlah kunjungan
  • 💰 Total nominal terkumpul
  • Breakdown status: Bayar / Janji / Belum / Tidak Ditemui / Pindah
  • 🏆 Top 3 petugas hari ini

Kartu Pengingat

Muncul otomatis kalau ada:

  • ⚠️ Terlewat — janji bayar atau kunjungan ulang yang sudah lewat

  • 🏠 Kunjungan Ulang — kunjungan ulang dalam 7 hari ke depan

Menu Cepat

Pencarian

  • ❌ Tombol clear (✕) — kosongkan pencarian dengan cepat
  • 📥 CSV — export daftar ke Excel/CSV

⚙️ 4. Filter Cerdas (Aktivis + Jenis Anggota) BARU

✨ BARU: Filter Aktivis dan Filter Jenis Anggota sekarang berdampingan agar mudah dipilih bersamaan.

Cara Pakai Filter

1. Filter Aktivis (📍)

Langkah 1: Klik tombol "📍 Semua Aktivis (35)" di beranda
Langkah 2: Centang aktivis yang mau ditampilkan
Langkah 3: Klik "✓ Terapkan Filter"
💡 Tips:
  • Tombol "✓ Pilih Semua" — centang semua aktivis
  • Tombol "✗ Kosongkan" — hapus centang semua
  • Ada kotak pencarian aktivis untuk filter cepat
  • Filter aktif muncul sebagai chip biru di bawah search box

2. Filter Jenis Anggota (⚙️)

Di sebelah filter aktivis ada filter jenis:

  • ⚙️ Semua Anggota — tampilkan semua
  • ⚠️ Hanya Menunggak — hanya yang menunggak
✅ Cara Kerja Bersamaan:
  • Pilih aktivis "Ahmad" + filter "Hanya Menunggak"
  • Hasil: hanya anggota menunggak milik Ahmad

Chip Filter Aktif

Kalau ada filter aktif, muncul chip di bawah search box:

  • Setiap chip menampilkan 1 aktivis terpilih
  • Klik ✕ di chip untuk hapus filter tersebut
  • Klik "✕ Reset" untuk hapus semua filter

👥 5. Daftar & Detail Anggota

Daftar Anggota

Di beranda, semua anggota ditampilkan dalam bentuk kartu. Setiap kartu berisi:

  • Nama lengkap & nama panggilan
  • CIF (nomor anggota)
  • Jenis pinjaman (badge kuning)
  • Alamat & desa
  • Tanggal jatuh tempo (JTO)
  • Staf pendamping & aktivis
  • Saldo pinjaman
  • Tagihan normal & tagihan program
  • Badge 🔒 PS (kalau ada Pembayaran Sementara) BARU
  • Badge ⚠️ X bulan (kalau menunggak)
⚠️ Kartu warna merah muda = anggota menunggak

Detail Anggota

Klik kartu anggota → muncul halaman detail dengan 5 section accordion:

📞 Section Kontak

  • No HP (dengan tombol Edit dan Salin)
  • Alamat lengkap

💰 Section Pinjaman

  • Tanggal jatuh tempo
  • Saldo pinjaman
  • Tagihan normal & tagihan program
  • Lama menunggak
  • Keterangan tunggakan
  • Info PS (kalau ada) — nominal, tanggal, keterangan BARU

💎 Section Simpanan

  • Saldo Pasallo'
  • Saldo Sepu'

🎯 Section Aksi

  • 📝 Proses Penanganan
  • 🏠 Kunjungan Multi-Anggota
  • 📄 Cetak KPKL (PDF)
  • 📱 Tombol WA Pengingat (4 jenis) BARU

📋 Section Riwayat

Tab-based:

  • 🏠 Kunjungan — semua riwayat kunjungan
  • 📝 Penanganan — riwayat telp/WA/surat
  • 📞 No HP — riwayat update nomor HP

Tombol Cepat

  • 📞 Telepon — langsung panggil nomor HP
  • 💬 WhatsApp — kirim pesan tagihan via WA
  • 🗺️ Maps — buka lokasi di Google Maps

Rumus Tagihan (Penting!)

📐 Rumus Tagihan Normal:
Angsuran = PokokJT + TunggakanPokok (kalau > 0), atau NilaiAngsuran (kalau = 0)
Total = Angsuran + Bunga + Denda + SimpananStandar → dibulatkan ke 10.000
📐 Rumus Tagihan Program:
Angsuran = PokokJT + TunggakanPokok (kalau > 0), atau Buffer (kalau = 0)
Total = Angsuran + Bunga + Denda + SimpananStandar → dibulatkan ke 10.000

🎯 6. Target Penanganan BARU

✨ FITUR BARU: Rencanakan siapa yang mau Anda kunjungi hari ini. Target membantu Anda fokus & memudahkan navigasi antar anggota.

Apa itu Target?

Target = daftar anggota yang Anda rencanakan untuk dikunjungi. Bisa dibuat sendiri atau ditugaskan oleh manager.

Cara Akses

Cara 1: Klik badge 🎯 Target Hari Ini di beranda
Cara 2: Klik sidebar ☰ → 🎯 Target Penanganan

Tambah Target (Self)

Langkah 1: Di halaman Target, klik "➕ TAMBAH TARGET"
Langkah 2: Pilih prioritas (Tinggi / Sedang / Rendah)
Langkah 3: Isi keterangan (opsional)
Langkah 4: Cari anggota dengan search box
Langkah 5: Klik anggota untuk pilih (bisa multi)
Langkah 6: Klik "💾 SIMPAN TARGET"

Target dari Manager (Assign)

Kalau manager menugaskan target ke Anda:

  • Badge target menampilkan target tersebut
  • Tombol 🗑️ Hapus diganti 🔒 (tidak bisa hapus)
  • Hubungi manager untuk hapus

Navigasi Antara Target BARU

✨ BARU: Saat buka detail anggota yang ada di target, muncul navigasi target di atas:
  • 🎯 Badge "TARGET" kuning
  • ⬅️ Tombol "Sebelumnya" (kunjungi target sebelumnya)
  • ➡️ Tombol "Berikutnya" (kunjungi target berikutnya)
  • Progress: Target 3 dari 15
  • Counter: Sesi ini: 2 kunjungan

Setelah Simpan Kunjungan

Kalau kunjungan disimpan dari target, akan muncul prompt:

✅ Kunjungan Tersimpan!
📝 Sesi ini: 2 kunjungan
📍 Posisi: 3 / 15
⏭️ Sisa: 12 anggota

[➡️ Lanjut] — ke target berikutnya
[🏠 Beranda] — selesai, balik ke beranda

Status Target

StatusKeterangan
⏳ PendingBelum dikunjungi
🔄 Sedang DikerjakanSedang diproses
✅ SelesaiSudah dikunjungi (auto setelah kunjungan)
❌ BatalDibatalkan

Multi-Select Hapus Target BARU

Langkah 1: Klik "☑️ PILIH MULTI"
Langkah 2: Centang target yang mau dihapus
Langkah 3: Klik "🗑️ HAPUS TERPILIH (N)"

🏠 7. Kunjungan (3 Metode)

Metode 1: Kunjungan Langsung (1 Anggota)

Langkah 1: Buka detail anggota
Langkah 2: Klik "PROSES PENANGANAN" → "Kunjungan Langsung"
Langkah 3: Isi form: tanggal, status, nominal, catatan, transportasi
Langkah 4: Upload foto bukti (kamera/galeri)
Langkah 5: Tanda tangan anggota (canvas)
Langkah 6: Klik "SIMPAN KUNJUNGAN"
💡 Tips: Foto otomatis diberi watermark (tanggal, lokasi GPS, nama petugas, nama anggota).

Keterangan Transportasi BARU

Field opsional untuk catat transportasi:

  • 🏍️ Motor Pribadi
  • 👥 Dibonceng [nama] — isi nama yang membonceng
  • 🚗 Mobil

Metode 2: Penagihan Tim (Multi Petugas)

Langkah 1: Klik "Proses Penanganan" → "Penagihan Tim"
Langkah 2: Pilih petugas yang ikut (min 2 orang)
Langkah 3: Isi status, nominal, foto, TTD
Langkah 4: Klik "SIMPAN"
✅ Keuntungan: Cukup 1 orang input. Kunjungan dihitung untuk semua petugas. Setoran tetap 1x.

Metode 3: Kunjungan Multi-Anggota (2-10 Anggota)

Langkah 1: Dari beranda → "Kunjungan Multi"
Langkah 2: Cari & pilih 2-10 anggota
Langkah 3: Isi status & nominal per anggota
Langkah 4: Isi catatan, foto, TTD (berlaku semua)
Langkah 5: Klik "SIMPAN"

💬 9. WA Pengingat BARU

✨ FITUR BARU: Kirim pengingat tagihan massal ke banyak anggota sekaligus. Hemat waktu!

Cara Akses

Cara 1: Klik tombol 📱 FAB (bulat hijau) di beranda
Cara 2: Dari detail anggota → section Aksi → tombol WA Pengingat

WA Pengingat Individual (dari Detail)

Di detail anggota, ada 4 tombol WA:

TombolUntuk
🔔 Pengingat JTOIngatkan tagihan jatuh tempo
⏰ Pengingat H-3Ingatkan 3 hari sebelum JTO
💎 Info PSInfo Pembayaran Sementara (kalau ada)
📅 Pengingat Janji BayarIngatkan janji bayar

WA Bulk (Massal)

Langkah 1: Klik tombol 📱 FAB di beranda
Langkah 2: Pilih filter: ⏰ JTO H-3 / 📅 JTO Hari Ini / ⚠️ JTO Lewat / 📋 Semua
Langkah 3: Modal preview muncul dengan daftar anggota
Langkah 4: Pilih jenis template (Tagihan / H-3 / Janji)
Langkah 5: Uncheck anggota yang tidak mau di-kirim
Langkah 6: Klik "📱 KIRIM WA"
✅ Filter Otomatis No HP Valid:
  • Anggota tanpa No HP tidak akan muncul di daftar
  • No HP invalid (kosong, strip, "xxx") otomatis di-skip
  • Hanya No HP format 62xxx (10-15 digit) yang lolos

Mode Pengiriman

ModeCara Kerja
📱 ManualBuka WhatsApp Web/App satu per satu (gratis)
🚀 GatewayKirim otomatis via API (butuh API key dari admin)
⚠️ Penting: Mode manual membuka WA satu per satu. Untuk 20+ anggota, butuh waktu. Siapkan WA Web atau WA App.

Log Pengiriman

Semua WA yang dikirim tercatat di log. Hubungi admin untuk lihat log.

📡 12. Mode Offline BARU

✨ FITUR BARU: Kerja tanpa internet! Data target bisa diunduh dulu, lalu dibuka kapan saja meski offline.

Kapan Pakai Mode Offline?

  • 📍 Kunjungan ke daerah yang sinyalnya lemah
  • 🏍️ Sedang di perjalanan tanpa internet
  • ⚡ Ingin buka data lebih cepat (dari cache, tidak perlu load server)

Cara Aktifkan Offline Mode

Step 1: Unduh Data Target (Online)

Langkah 1: Pastikan online + sudah ada target
Langkah 2: Buka beranda → tunggu sampai target ke-load
Langkah 3: Klik tombol 📥 Unduh Data Offline
Langkah 4: Tunggu progress bar selesai (~30 detik untuk 15 target)
✅ Setelah selesai:
Badge target berubah: "✅ Siap offline (15 target)"

Step 2: Kerja Offline

Langkah 1: Matikan WiFi / data seluler
Langkah 2: Beranda otomatis filter hanya target
Langkah 3: Banner biru "Mode Target (Offline)" muncul
Langkah 4: Buka detail anggota target → data dari cache
Langkah 5: Kunjungan bisa di-save offline → masuk queue
Langkah 6: Sync otomatis saat kembali online

Indikator Offline

  • 📡 Badge koneksi di header (🌐 online / 📡 offline)
  • ⏳ Badge pending — jumlah data menunggu sync
  • 🎯 Banner "Mode Target (Offline)" — filter hanya target

Batasan Offline

BisaTidak Bisa
✅ Buka detail anggota target❌ Buka detail di luar target
✅ Simpan kunjungan (queue)❌ Kirim WA
✅ Lihat riwayat❌ Load data baru
✅ Filter & search❌ Update profil

Sync Otomatis

Saat kembali online:

  • Toast muncul: "🌐 Online! Sync N data..."
  • Data queue otomatis di-sync ke server
  • Badge pending hilang

Kelola Queue Manual

Klik badge pending di header untuk:

  • Lihat semua data menunggu
  • 🔄 Sync Sekarang — paksa sync manual
  • 🔄 Retry — coba sync item gagal
  • 🗑️ Hapus — buang item (kalau data sudah tidak perlu)

📅 15. Alur Kerja Harian

Pagi (07:00 - 09:00) — Persiapan

  1. Login ke aplikasi
  2. Cek Dashboard — perhatikan angka hari ini
  3. Cek Badge Target — berapa target hari ini?
  4. Cek Pengingat — ada janji bayar / kunjungan ulang?
  5. Kalau ada target: klik 📥 Unduh Data Offline (persiapan)
  6. Kalau tidak ada target: buka 🎯 Target Penanganan → tambah target

Siang (09:00 - 15:00) — Kunjungan

  1. Kunjungi anggota sesuai urutan target
  2. Setelah kunjungan, simpan di aplikasi
  3. Kalau ada target berikutnya, klik ➡️ Lanjut
  4. Foto bukti + tanda tangan
  5. Kirim WA untuk info transfer (kalau perlu)
  6. Kalau ada yang bayar tunai → catat setoran

Sore (15:00 - 17:00) — Rekap

  1. Cek semua kunjungan sudah ter-input
  2. Input setoran final
  3. Kirim WA massal ke yang belum bayar
  4. Cetak surat (Surat Tagihan / SP1 / SP2 / SP3)
  5. Cek sisa target hari ini

Malam (17:00+) — Evaluasi

  1. Cek Statistik Hari Ini
  2. Cek Top Petugas
  3. Rencana target besok

🔧 16. Troubleshooting

Aplikasi Lambat Loading

  • Refresh halaman (Ctrl+Shift+R)
  • Cek koneksi internet
  • Tunggu 5-10 detik pertama (cache warm)
  • Refresh lagi — harus lebih cepat

Foto Tidak Ter-upload

  • Cek ukuran foto — max 10 MB
  • Kompres dulu dengan aplikasi editor
  • Coba ambil ulang dari kamera
  • Cek izin kamera di browser

GPS Tidak Terdeteksi

  • Buka pengaturan browser → izinkan akses lokasi
  • Keluar ruangan atau cari sinyal
  • Foto tetap bisa disimpan (tanpa koordinat)

Data Tidak Muncul

  • Hard refresh (Ctrl+Shift+R)
  • Cek filter aktivis — mungkin semua ter-filter
  • Cek filter menunggak
  • Logout & login ulang

Tombol "Unduh Offline" Tidak Muncul

⚠️ Penyebab: Belum ada target aktif. Tombol unduh offline hanya muncul kalau Anda punya target.

Solusi: Buka 🎯 Target Penanganan → tambah target dulu.

Offline Mode Tidak Bisa Buka Detail

  • Pastikan sudah unduh data offline sebelumnya (saat online)
  • Detail anggota bukan target tidak bisa dibuka offline
  • Balik online → buka detail sekali → cache tersimpan

Kunjungan Offline Tidak Ter-sync

  • Cek badge pending di header — ada angka?
  • Klik badge pending → 🔄 Sync Sekarang
  • Kalau masih gagal: cek koneksi, coba lagi 5 menit lagi

WA Bulk Tidak Terkirim

  • Cek apakah anggota punya No HP valid
  • Mode manual: buka WhatsApp dulu
  • Mode gateway: hubungi admin (mungkin API key belum diisi)
  • Kalau lebih dari 20 anggota: kirim bertahap

Filter Aktivis Tidak Berfungsi

  • Pastikan klik "✓ Terapkan Filter" setelah centang
  • Cek chip filter muncul di bawah search box
  • Kalau chip muncul tapi data tidak berubah: refresh halaman

Lupa Password

Hubungi admin → admin reset password lewat Setup Petugas.

Setoran Pending Terus

Setoran menunggu approval admin. Hubungi admin untuk approve.

❓ 18. FAQ (Pertanyaan Umum)

Q: Lupa password, bagaimana?

A: Hubungi admin. Admin reset password via Menu Admin → Setup Petugas → Reset Password.

Q: Foto tidak ter-upload, kenapa?

A: Cek ukuran foto. Maksimal 10 MB. Kompres dulu kalau lebih.

Q: GPS tidak terdeteksi, bagaimana?

A: Buka pengaturan browser → izinkan akses lokasi.

Q: Setoran saya pending terus, kenapa?

A: Setoran menunggu approval dari admin.

Q: Apa itu Target Penanganan? BARU

A: Target = daftar anggota yang Anda rencanakan untuk dikunjungi. Membantu Anda fokus & mudah navigasi antar anggota. Bisa dibuat sendiri atau ditugaskan manager.

Q: Bagaimana cara tambah target?

A: Menu 🎯 Target Penanganan → "➕ TAMBAH TARGET" → pilih prioritas → cari & pilih anggota → SIMPAN.

Q: Kenapa tombol "Unduh Offline" tidak muncul?

A: Tombol ini hanya muncul kalau Anda punya target aktif. Tambah target dulu di menu Target Penanganan.

Q: Bagaimana cara kerja Mode Offline?

A:
1. Saat online: klik 📥 Unduh Data Offline untuk cache detail target
2. Saat offline: beranda otomatis filter hanya target
3. Buka detail target → data dari cache
4. Simpan kunjungan → masuk queue
5. Saat online lagi: auto-sync

Q: Bisa buka detail anggota di luar target saat offline?

A: Tidak bisa. Hanya detail anggota target yang di-cache. Untuk buka yang lain, harus online dulu.

Q: Bagaimana cara kirim WA ke banyak anggota?

A: Klik tombol 📱 FAB di beranda → pilih filter (H-3/Hari Ini/Lewat/Semua) → pilih template → KIRIM WA. Anggota tanpa No HP valid otomatis di-skip.

Q: WA Bulk di-skip karena apa?

A: Hanya anggota dengan No HP valid (format 62xxx, 10-15 digit) yang lolos. No HP kosong / strip / "xxx" otomatis di-skip.

Q: Bagaimana cara cetak surat ulang?

A: Menu Persuratan → Daftar Surat → cari surat → klik 🖨️ Cetak Ulang.

Q: Angka statistik berbeda dengan kemarin, kenapa?

A: Statistik hari ini di-reset harian. Untuk data bulanan, lihat di Rekap Bulanan.

Q: Tagihan normal & program beda, kenapa?

A: - Normal = pakai angsuran penuh (PokokJT + TunggakanPokok, atau NilaiAngsuran) - Program = pakai PokokJT + TunggakanPokok, atau Buffer (untuk keringanan)

Q: Kenapa total tagihan dibulatkan?

A: Pembulatan ke 10.000 memudahkan pembayaran. Selisih pembulatan ditambahkan ke Angsuran Pinjaman (khusus di surat).

Q: Apa itu PS (Pembayaran Sementara)? BARU

A: PS = dana talangan internal yang ditambahkan ke tagihan anggota. Hanya Staf/Manager/Admin yang bisa lihat nominal PS. Badge 🔒 PS muncul di kartu anggota kalau ada.

Q: Apakah bisa kirim WA otomatis? BARU

A: Ya, kalau admin sudah setup Mode GATEWAY dengan API key (Fonnte/Wablas). Kalau masih MANUAL, WA akan terbuka satu per satu.

Q: Apakah data bisa di-backup?

A: Ya, tapi hanya admin yang bisa. Menu Admin → Backup Database → Backup Sekarang.

Q: Bagaimana kalau HP saya lowbat saat kunjungan offline?

A: Data kunjungan yang belum di-save akan hilang. Selalu save kunjungan langsung setelah kunjungan, tidak menunggu.
