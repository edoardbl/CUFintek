🎯 3. Target Penanganan BARU

✨ Fitur Baru! Rencanakan siapa yang mau Anda kunjungi hari ini. Target membantu Anda fokus & memudahkan navigasi antar anggota.

Apa itu Target?

Target = daftar anggota yang Anda rencanakan dikunjungi. Bisa dibuat sendiri atau ditugaskan manager.

Cara Akses

1
Klik badge 🎯 Target Hari Ini di beranda
2
Atau klik sidebar ☰ → 🎯 Target Penanganan

Tambah Target

1
Klik "➕ TAMBAH TARGET"
2
Pilih prioritas: Tinggi / Sedang / Rendah
3
Isi keterangan (opsional)
4
Cari & pilih anggota (bisa multi)
5
Klik "💾 SIMPAN TARGET"

Navigasi Target BARU

🎯 Navigasi Otomatis Saat buka detail anggota yang ada di target, muncul navigasi:
  • ⬅️ Tombol "Sebelumnya"
  • ➡️ Tombol "Berikutnya"
  • Progress: Target 3 dari 15

Setelah Simpan Kunjungan

Kalau kunjungan disimpan dari target, muncul prompt:
✅ Kunjungan Tersimpan!
📍 Posisi: 3 / 15
⏭️ Sisa: 12 anggota

[➡️ Lanjut] ke target berikutnya
[🏠 Beranda] selesai

Status Target

⏳ Pending — belum dikunjungi
🔄 Sedang Dikerjakan — sedang diproses
✅ Selesai — sudah dikunjungi (otomatis)
❌ Batal — dibatalkan
✅ Tips Fokus kunjungi target hari ini dulu. Setelah selesai, baru tambah target baru.

👥 4. Daftar & Detail Anggota

Daftar Anggota (Beranda)

Semua anggota binaan Anda muncul sebagai kartu. Setiap kartu berisi:

  • Nama & panggilan
  • CIF & jenis pinjaman
  • Alamat & desa
  • JTO (tanggal jatuh tempo)
  • Staf pendamping
  • Saldo, Tagihan Normal & Program
  • Badge ⚠️ X bulan (kalau menunggak)
⚠️ Perhatian Kartu warna merah muda = anggota menunggak.

Detail Anggota (Klik Kartu)

Info lengkap dengan 5 section accordion:

  • 📞 Kontak — No HP (Edit / Salin) & alamat
  • 💰 Pinjaman — JTO, saldo, tagihan, lama menunggak
  • 💎 Simpanan — Saldo Pasallo' & Sepu'
  • 🎯 Aksi — Proses penanganan, kunjungan multi, cetak KPKL, WA pengingat
  • 📋 Riwayat — Tab kunjungan, penanganan, update No HP
🔘 Tombol Aksi Cepat
📞 Telepon · 💬 WhatsApp · 🗺️ Maps
📝 Tombol Penanganan

💬 7. WA Pengingat BARU

✨ Fitur Baru! Kirim pengingat tagihan ke banyak anggota sekaligus. Hemat waktu!

Cara Akses

1
Klik tombol 📱 FAB (bulat hijau) di beranda
2
Atau dari detail anggota → section Aksi → tombol WA

WA Pengingat Individual

Di detail anggota, ada 4 tombol WA:

🔔 Pengingat JTO — ingatkan tagihan jatuh tempo
⏰ Pengingat H-3 — ingatkan 3 hari sebelum JTO
💎 Info PS — info Pembayaran Sementara (kalau ada)
📅 Pengingat Janji Bayar — ingatkan janji bayar

WA Bulk (Massal)

1
Klik tombol 📱 FAB di beranda
2
Pilih filter: ⏰ H-3 / 📅 Hari Ini / ⚠️ Lewat / 📋 Semua
3
Modal preview muncul dengan daftar anggota
4
Pilih jenis template (Tagihan / H-3 / Janji)
5
Uncheck anggota yang tidak mau di-kirim
6
Klik "📱 KIRIM WA"
✅ Filter Otomatis No HP Valid • Anggota tanpa No HP tidak akan muncul
• No HP invalid (kosong, strip, "xxx") otomatis di-skip
• Hanya No HP format 62xxx (10-15 digit) yang lolos
⚠️ Penting WA bulk membuka WA satu per satu. Untuk 20+ anggota, butuh waktu. Siapkan WhatsApp Web/App.

📡 10. Mode Offline BARU

✨ Fitur Baru! Kerja tanpa internet! Data target bisa diunduh dulu, lalu dibuka kapan saja meski offline.

Kapan Pakai Mode Offline?

  • 📍 Kunjungan ke daerah yang sinyalnya lemah
  • 🏍️ Sedang di perjalanan tanpa internet
  • ⚡ Ingin buka data lebih cepat

Step 1: Unduh Data Target (Online)

1
Pastikan online + sudah ada target
2
Buka beranda → tunggu sampai target ke-load
3
Klik tombol 📥 Unduh Data Offline
4
Tunggu progress bar selesai (~30 detik)
✅ Setelah selesai Badge target berubah: "✅ Siap offline (X target)"

Step 2: Kerja Offline

1
Matikan WiFi / data seluler
2
Beranda otomatis filter hanya target
3
Banner biru "Mode Target (Offline)" muncul
4
Buka detail anggota target → data dari cache
5
Kunjungan bisa disimpan offline → masuk queue
6
Sync otomatis saat kembali online

Indikator Offline

📡 Badge koneksi di header (🌐 online / 📡 offline)
⏳ Badge pending — jumlah data menunggu sync
🎯 Banner "Mode Target" — filter hanya target

Batasan Offline

✅ Bisa: buka detail target, simpan kunjungan, lihat riwayat, filter
❌ Tidak bisa: buka non-target, kirim WA, load data baru
⚠️ Penting Selalu save kunjungan langsung setelah kunjungan. Jangan tunggu HP mati.

🔧 14. Jika Ada Masalah

😴 Aplikasi Lambat / Loading Lama
• Tunggu 5-10 detik (pertama kali buka)
• Refresh halaman (tarik ke bawah)
• Cek koneksi internet
📷 Foto Tidak Ter-upload
• Cek ukuran foto — max 10 MB
• Kompres dulu atau ambil ulang
• Coba pakai kamera langsung
📍 GPS Tidak Terdeteksi
• Buka pengaturan browser HP
• Izinkan akses lokasi
• Keluar ruangan / cari sinyal
📥 Tombol "Unduh Offline" Tidak Muncul BARU
Penyebab: Belum ada target.
Solusi: Buka 🎯 Target Penanganan → tambah target dulu.
📡 Offline Mode Tidak Bisa Buka Detail BARU
• Pastikan sudah unduh data offline sebelumnya
• Detail anggota bukan target tidak bisa dibuka offline
• Balik online → buka detail sekali → cache tersimpan
⏳ Kunjungan Offline Tidak Ter-sync BARU
• Cek badge pending di header — ada angka?
• Klik badge pending → 🔄 Sync Sekarang
• Kalau gagal, cek koneksi lalu coba lagi
💬 WA Bulk Tidak Terkirim BARU
• Cek apakah anggota punya No HP valid
• Mode manual: buka WhatsApp dulu
• Kalau > 20 anggota: kirim bertahap
❓ Data Tidak Muncul
• Refresh halaman
• Logout & login ulang
• Hubungi admin jika masih kosong
🔑 Lupa Password
Hubungi Admin untuk reset password.

Hubungi Admin untuk approve setoran.

❓ 15. FAQ (Sering Ditanya)

Apa itu Target Penanganan? BARU
Target = daftar anggota yang Anda rencanakan dikunjungi. Membantu Anda fokus & memudahkan navigasi antar anggota. Bisa dibuat sendiri atau ditugaskan manager.
Bagaimana cara tambah target?
Menu 🎯 Target Penanganan → "➕ TAMBAH TARGET" → pilih prioritas → cari & pilih anggota → SIMPAN.
Kenapa tombol "Unduh Offline" tidak muncul? BARU
Tombol ini hanya muncul kalau Anda punya target aktif. Tambah target dulu di menu Target Penanganan.
Bagaimana cara kerja Mode Offline? BARU
1. Saat online: klik 📥 Unduh Data Offline untuk cache detail target
2. Saat offline: beranda otomatis filter hanya target
3. Buka detail target → data dari cache
4. Simpan kunjungan → masuk queue
5. Saat online lagi: auto-sync
Bisa buka detail non-target saat offline? BARU
Tidak bisa. Hanya detail anggota target yang di-cache. Untuk buka yang lain, harus online dulu.
Bagaimana cara kirim WA ke banyak anggota? BARU
Klik tombol 📱 FAB di beranda → pilih filter (H-3/Hari Ini/Lewat/Semua) → pilih template → KIRIM WA. Anggota tanpa No HP valid otomatis di-skip.
Kenapa saya hanya melihat sebagian anggota?
Sebagai Aktivis, Anda hanya melihat anggota yang menjadi binaan Anda. Anggota lain dikelola oleh Aktivis lain.
Kenapa Tagihan Normal & Program berbeda?
Normal = pakai angsuran penuh.
Program = pakai angsuran keringanan (PokokJT atau Buffer).
Untuk anggota dengan PokokJT > 0, Normal & Program sama.
Setoran saya pending terus, kenapa?
Setoran menunggu approval admin. Hubungi admin untuk approve.
Bagaimana cara mengubah No HP anggota?
Buka detail anggota → klik ✏️ Edit Nomor HP → isi nomor baru → Simpan.
